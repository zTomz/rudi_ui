# Rudi UI example

This is the minimal, dependency-free example application for the `rudi_ui`
package. It demonstrates the application shell, theme, page surface, primary
actions and feedback states using only Flutter and the local package.

Run it from this directory:

```shell
flutter pub get
flutter run
```

For the complete interactive component catalog with device presets, light and
dark themes and component states, use the repository's `preview/` application
or open the [hosted showcase](https://ztomz.github.io/rudi_ui/).
