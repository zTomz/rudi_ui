# rudi_ui_fonts

Optional typography assets for [`rudi_ui`](https://pub.dev/packages/rudi_ui).
The package adds Google Sans for body text and Unbounded for display roles.

```dart
import 'package:rudi_ui/rudi_ui.dart';
import 'package:rudi_ui_fonts/rudi_ui_fonts.dart';

final theme = RudiThemeData.light().withRudiFonts();
```

The bundled fonts remain licensed under the SIL Open Font License 1.1. Their
license texts are included next to the respective assets.
